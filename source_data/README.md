# Source data package

This directory contains the numerical source data transcribed from the HG-GS manuscript tables and summary statistics. It is intended to let editors and reviewers verify the plotted/table values reported in the manuscript.

Included files:

- `table1_main_results.csv`: average quality, semantic-detail fidelity, and compression values across five objects.
- `table2_matched70.csv`: near-70 MB matched-budget comparison.
- `semantic_augmented_controls.csv`: semantic-augmented RDO-Gaussian and ContextGS control values discussed in the Results.
- `user_study_summary.csv`: participant-level summary statistics and Holm-adjusted p-values reported for the pilot AR study.

Restricted original artifact image sets are not included because of artifact permissions and image-rights restrictions. Rendered evaluation images, camera trajectories, per-run logs, and annotation statistics should be deposited here or in an archival repository before final publication if permissions allow.
